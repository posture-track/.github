# Sit-Back 개요

**Sit-Back**은 사용자의 앉은 자세를 촬영하고, AI 분석 결과를 통해 실시간 피드백과 리포트를 제공하는 자세 교정 피드백 시스템입니다.
앱, 서버, AI 모델이 유기적으로 연결되어 작동하며, 다음과 같은 흐름을 가집니다.

---

## 핵심 흐름

### 앱 (Flutter)

* 촬영 시작
* 사진 촬영 후 Flask 서버에 이미지 전송
* 분석 결과를 받고 Spring 서버에 저장 요청
* 사용자에게 점수, 리포트, 그래프 제공

### Flask 서버 (Python + YOLOv8)

* 전송된 이미지를 기반으로 목과 허리 각도 추출
* 분석 결과를 JSON 형태로 Flutter에 전달

### Spring 서버 (Java + Spring Boot)

* 사용자 인증 (JWT, 일반 로그인 + 카카오 로그인)
* 분석 결과 저장 및 리포트 생성
* 월별 평균 점수, 일별 리포트 리스트 등 API 제공

---

## 주요 기능 요약

### 앱

* 일반 로그인 / 카카오 소셜 로그인
* 분석 결과 UI 피드백 제공
* 월간 점수, 일일 리포트 그래프 시각화
* 상태관리: Bloc 구조 기반
* Glassmorphic 스타일 UI → 현재 기능 중심 UI로 리팩토링

### 서버

* JWT 기반 인증 및 토큰 갱신 구조 구현
* Access/Refresh 토큰 분리 및 재발급 처리
* 리포트 및 점수 API 설계 완료 (월간/일간 조회)

### AI 모델

* YOLOv8 기반으로 사람을 탐지
* 목 각도, 허리 각도, 측면 판별
* 해당 값에 따라 "좋음 / 주의 / 심각" 판정

---

## 데이터 흐름 예시

```plaintext
Flutter 앱
  ↓ (사진 전송)
Flask (YOLOv8 분석)
  ↓ (자세 결과)
Flutter 앱
  ↓ (JSON 결과 전송)
Spring 서버 (DB 저장 및 응답)
```

## 담당 역할

### 조철민

* 전체 시스템 아키텍처 설계
* Spring Boot 서버 개발 (REST API, JWT 인증, 리포트 저장 로직 등)
* Flutter 앱 개발 (상태관리 Bloc, UI 구성, 페이지 라우팅)
* Flutter ↔ Flask ↔ Spring 간 통신 로직 구현
* 일반/카카오 로그인 기능 구현 및 토큰 갱신 처리
* UI 디자인 구조 리팩토링 및 Glassmorphic → 기능 중심 UI 전환
* 데이터 흐름 설계 및 API 명세 작성

### 류태웅

* YOLOv8 기반 AI 자세 분석 모델 개발 (Flask 서버 구축 포함)
* AWS EC2, RDS를 이용한 Spring/Flask 서버 배포 및 클라우드 인프라 구성
* 앱 전체 디자인의 골격(스타일 가이드, 기본 구조 등) 설계

### 박성찬

* 초기 앱 아이디어 및 기능 기획 일부 참여
* 사용자 요구사항 정의 일부 기여

## 향후 계획

### Google Play Store APK 배포

* 실제 사용자 피드백 수집을 위한 베타 테스트 예정
* 버전 관리 및 업데이트 자동화 준비

### 멀티스레드 환경 대응

* Spring 서버에서 사용자별로 개별 `ArrayList<PostureData>`를 분배
* 다양한 사용자가 동시에 서버에 접근해도 서로의 데이터가 섞이지 않도록 구조 개선
* 동시 요청 상황에서도 정확한 리포트 생성이 가능하도록 Thread-safe 설계 적용
